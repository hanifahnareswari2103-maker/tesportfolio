# Narisshani Portfolio

**Strategy Meets Story**

## About the Project

This personal portfolio was built by Nariswari Sahasika Hanifah, a 2nd Semester Entrepreneurship Business Creation student. It uses plain HTML5, CSS3 and Vanilla JavaScript to deliver a clean, responsive experience. The design philosophy centers on entrepreneurial strategy, structured execution, and visual storytelling; each element is crafted to showcase market relevance and sustainable growth.

## Key Features

- **Responsive Design**: Mobile-first layout that adapts across screen sizes.
- **Theme Switching**: Dark/light mode toggle with system preference detection and persistence.
- **Structured Layout**: Component-based sections for hero, about, projects, and contact.
- **Project Showcasing**: Highlighted case studies with visuals, descriptions, and links.
- **Smooth Scrolling & Header Effects**: Polished navigation interactions.

## Featured Projects

### Content & Photo Portfolio
A curated gallery of photography and content work showcasing creative storytelling and concept-driven visuals.

### Market Research & Expansion Analysis
An analytical project focused on market trends, consumer behavior, and scalable business model development.

### Event Management & Coordination
A case study of planning, team delegation, and operational workflow management for organizational programs.

## Local Setup

To view or modify the site locally, follow these steps:

```bash
# Clone the repository
git clone <repository-url> narisshani-portfolio

# Navigate into the project folder
cd narisshani-portfolio

# Open the files in your preferred editor or simply open index.html in a browser
``` 

No additional build tools or dependencies are required; the site runs purely on static assets.
